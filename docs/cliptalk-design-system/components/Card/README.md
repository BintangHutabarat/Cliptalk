# Card

Panel dengan garis tepi 1px dan radius `radius-lg`, tanpa bayangan.

- Konsumen memberi: `title`, `description`, `action` (elemen di kanan header), `children`, `footer` (tombol rata kanan), `flush` (body tanpa padding, untuk daftar bergaris).
- Jangan menumpuk Card di dalam Card. Satu layar biasanya berisi 1–3 Card; pengaturan berjajar memakai SettingRow di dalam satu `.ct-settings`, bukan kartu-kartu terpisah.

# Badge

Satu sampai tiga kata status atau nilai di samping objek.

- `tone`: `neutral` | `outline` | `range` | `success` | `warning` | `destructive`. `mono` untuk angka (skor, resolusi).
- `range` hanya untuk skor kandidat ≥ 90 atau penanda "Terpilih"; bukan untuk status umum.
- Status selalu berupa kata ("Klip siap"), bukan warna saja. `success` boleh diberi `icon: 'check'`.

# Icon

Ikon garis 24×24, stroke 1.75, mewarisi `currentColor`.

- `name`: `upload` `film` `check` `play` `download` `back` `close` `info` `alert` `scissors` `captions`. `size` default 16. `label` bila ikon berdiri sendiri (jadi `role="img"`).
- Di aplikasi Laravel, pakai Lucide (`lucide-react` / `lucide-vue-next` / Blade Lucide) dengan stroke 1.75 — set ini meniru bentuk Lucide untuk pratinjau.
- Tanpa emoji di UI.

# Input

Kolom teks dengan label, penghitung karakter opsional, dan petunjuk.

- Konsumen memberi: `id` (wajib, stabil), `label`, `value` + `onChange`, `maxLength` (menampilkan `34/60`), `hint`, `error` (menggantikan hint, merah).
- Pesan error menjelaskan cara memperbaiki: "Judul maksimal 60 karakter. Hapus 4 karakter."

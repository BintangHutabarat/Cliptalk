# SettingRow

Satu baris pengaturan ala buku besar: judul + deskripsi kiri, kontrol kanan.

- Konsumen memberi: `title`, `description`, `children` (kontrol). Bungkus beberapa baris dalam `<div class="ct-settings">`; garis pemisah muncul otomatis.
- Nilai yang belum bisa diubah ditampilkan sebagai teks `ct-setting-value`, bukan kontrol nonaktif.
